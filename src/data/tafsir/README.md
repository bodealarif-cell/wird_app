# ملفات التفسير

ضع هنا ملفًا لكل تفسير باسم `معرّف.json` (مثل `muyassar.json`)، بهذا الشكل:

```json
{
  "meta": { "name": "التفسير الميسر", "author": "مجمع الملك فهد" },
  "t": { "1": ["تفسير الآية ١ من الفاتحة", "تفسير الآية ٢"], "2": ["..."] }
}
```

المفتاح في `t` هو رقم السورة، وقيمته مصفوفة بتفسير كل آية بالترتيب.
لتحويل ملفات جاهزة: `node scripts/import-tafsir.mjs الملف.json معرّف "الاسم" "المؤلف"`
