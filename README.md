# وِرد — ورد اليوم فقط

تطبيق أندرويد لحفظ القرآن بتركيز: يعرض لك ورد اليوم وحده من صفحة مصحف المدينة، ويخفي الباقي. وفيه قارئ مصحف كامل (٦٠٤ صفحات) دون أي إخفاء.

**التقنيات:** React 19 · Vite · Zustand · Framer Motion · lucide-react · Capacitor 8

## الحصول على ملف APK (بدون تثبيت أي أدوات)
1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه محتويات هذا المجلد كما هي (أقل من ١٠٠ ملف، فيناسب الرفع من المتصفح). مجلد android لا يُرفع، فيولّده خادم GitHub تلقائيًا أثناء البناء.
2. افتح تبويب **Actions** ← **بناء تطبيق أندرويد (APK)** ← **Run workflow**.
3. بعد نحو ٥–١٠ دقائق افتح التشغيل المكتمل ونزّل `wird-apk` من قسم **Artifacts**، ففيه `wird.apk`.
4. انقله إلى هاتفك وثبّته (فعّل «التثبيت من مصادر غير معروفة» إن طُلب).

لنشر الملف برابط ثابت: أنشئ وسمًا مثل `v1.0.0` (git tag v1.0.0 && git push --tags) فيُرفق الملف تلقائيًا في صفحة **Releases**. ثم ضع رابط تلك الصفحة في `src/config.js` ليعمل زر «شارك وِرد».

> الملف الناتج نسخة تجريبية (debug) موقّعة بمفتاح تجريبي، وهي مناسبة للتجربة والتوزيع بين الأصدقاء. للنشر في متجر Google Play تحتاج إلى نسخة release بمفتاح توقيع خاص بك.

## التطوير محليًا
```
npm install
npm run dev          # معاينة في المتصفح
npx cap add android  # مرة واحدة لتوليد مشروع أندرويد محليًا
node scripts/patch-android.mjs
npm run android:sync # بناء الويب ومزامنته
npm run android:open # فتح المشروع في Android Studio
```

## المصادر والتراخيص (مهم قبل النشر العام)
- نص القرآن: ملف Quran-Json (AbdAlftahSalem). دقّقه على مصحف مطبوع موثوق قبل النشر.
- تقطيع صفحات مصحف المدينة وأسطره: zonetecde/mushaf-layout (أُصلحت فيه ثلاثة عيوب في الصفحات ٢٠٧ و٥٨٦ و٥٩٠).
- خط المصحف KFGQPC Uthmanic Script HAFS: ملك لمجمع الملك فهد لطباعة المصحف الشريف، وترخيصه يمنع إعادة توزيعه أو تعديله دون إذن كتابي. اطلب الإذن أو راجع شروط الاستخدام في fonts.qurancomplex.gov.sa قبل نشر التطبيق علنًا.
- خطوط الواجهة: IBM Plex Sans Arabic وReem Kufi (SIL OFL).
